# DataSave

Application web/PWA de stockage local de données.

## Fonctionnalités
- Ajout, modification et suppression de fiches
- Recherche instantanée
- Catégories
- Favoris
- Copie du contenu
- Verrouillage par PIN
- Export/import JSON
- Fonctionnement hors ligne via Service Worker
- Logo DataSave inclus

## Lancer
Ouvrir `index.html` dans un navigateur moderne.
Pour l'installation PWA/offline complète, servir le dossier avec un petit serveur HTTP.
